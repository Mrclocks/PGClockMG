# 🕒 PGClockMG

**Восстановление и миграция на PasarGuard**

`v1.0beta` · порт `7000` · فارسی / English / Русский

</div>

---

## ⚠️ Перед началом

| | |
|---|---|
| 🧪 **Бета** | Сборка ещё не полностью стабилизирована. На боевом сервере учитывайте риск. |
| 💾 **Сделайте бэкап** | Перед restore или миграцией сделайте полный бэкап панели, базы данных и важных файлов. |
| 🛠️ **Установка панели** | Этот мастер **не** устанавливает PasarGuard. Сначала установите панель сами, затем вернитесь для restore или миграции. |

---

## ✨ Что умеет этот инструмент?

| Задача | Описание |
|--------|----------|
| ♻️ **Restore / смена БД** | Восстанавливает бэкап PasarGuard — даже если тип базы отличается от прежнего |
| 🚚 **Миграция** | Переносит данные из панелей вроде Marzban, 3x-ui, Remnawave и Hiddify |
| 📘 **Гайд** | Если панель установлена — показывает её параметры; если нет — только официальные команды установки |

Примечание: restore всегда идёт в ту базу, которая сейчас установлена на сервере.

---

## 🚀 Установка

```bash
sudo bash -c "$(curl -fsSL 'https://raw.githubusercontent.com/Mrclocks/PGClockMG/main/install.sh?v='$(date +%s))"
```

После установки откройте: **`http://SERVER_IP:7000`**

📋 Требования: Ubuntu или Debian · root · Docker · порт `7000`

---

## 📦 Поддержка панелей

| Источник | Статус |
|----------|--------|
| 🟢 Marzban | Полная |
| 🟢 PasarGuard (restore) | Полная |
| 🟡 3x-ui | Частичная |
| 🟠 Remnawave / Hiddify | Экспериментальная |

---

## 🧰 Полезные команды

```bash
systemctl status pg-migrator
systemctl restart pg-migrator
journalctl -u pg-migrator -f

# Обновление до последней версии
sudo bash -c "$(curl -fsSL 'https://raw.githubusercontent.com/Mrclocks/PGClockMG/main/install.sh?v='$(date +%s))"

# Когда закончили работу
systemctl stop pg-migrator && systemctl disable pg-migrator
```

---

## 🔒 Конфиденциальность

Всё выполняется только на вашем сервере. Бэкапы и пароли никуда за пределы сервера не отправляются.
