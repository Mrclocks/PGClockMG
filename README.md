# PGClockMG

🧰 ویزارد ریستور و مهاجرت + پنل بکاپ PasarGuard

</div>

---

## ✨ معرفی

PGClockMG دو سرویس کنار هم است:

| سرویس | پورت پیش‌فرض | کار |
|--------|---------------|-----|
| 🧭 **ویزارد** (`pg-migrator`) | `7000` | ریستور بکاپ و مهاجرت به PasarGuard |
| 💾 **پنل بکاپ** (`pg-backup`) | `7001` | بکاپ کامل، تلگرام، زمان‌بندی و استریم برای ریستور |

هر دو با یک بار اجرای `install.sh` نصب می‌شوند. منوی نصب گزینهٔ جدا برای بکاپ ندارد — فقط پورت هر سرویس را می‌پرسد.

> 📌 این ابزار خودش PasarGuard را نصب نمی‌کند. اول پنل را نصب کنید، بعد برگردید.

---

## 📦 پیش‌نیازها

- Ubuntu 22.04+
- دسترسی `root`
- Docker
- PasarGuard از قبل روی سرور نصب شده باشد (برای بکاپ و ریستور)

| آدرس | توضیح |
|------|--------|
| `http://SERVER_IP:7000/?token=...` | ویزارد — با **توکن دسترسی** |
| `http://SERVER_IP:7001/` | پنل بکاپ — با **رمز قوی** در اولین ورود |

بازیابی توکن ویزارد:

```bash
cat /opt/pg-migrator/.access_token
```

## 📥 نصب

```bash
sudo bash -c "$(curl -fsSL 'https://raw.githubusercontent.com/Mrclocks/PGClockMG/main/install.sh?v='$(date +%s))"
```

بعد از اجرا، اسکریپت صفحه را پاک می‌کند و منوی اصلی را نشان می‌دهد.

### 🗂️ منوی اسکریپت

| گزینه | کار |
|-------|-----|
| ۱ · Install / update | پورت ویزارد (`7000`) و پورت بکاپ (`7001`) را می‌پرسد، هر دو سرویس را نصب/آپدیت می‌کند و URLها را چاپ می‌کند |
| ۲ · Uninstall | سرویس‌ها و `/opt/pg-migrator` را پاک می‌کند و پیشنهاد می‌دهد بکاپ‌ها را نگه دارید. PasarGuard دست‌نخورده می‌ماند |
| ۳ · Redirect server | وضعیت، ری‌استارت و لاگ `pg-redirect` — فقط برای مهاجرت 3x-ui / Hiddify |
| ۴ · Exit | خروج از منو |

بالای منو وضعیت PasarGuard، Docker و سرویس‌ها نمایش داده می‌شود.

### نصب بدون سؤال

```bash
sudo PG_MIGRATOR_PORT=7000 PG_BACKUP_PORT=7001 bash -c "$(curl -fsSL 'https://raw.githubusercontent.com/Mrclocks/PGClockMG/main/install.sh?v='$(date +%s))"
```

`PG_MIGRATOR_ACTION`: `install` · `uninstall` · `redirect-restart` · `menu`  
با `PG_MIGRATOR_YES=1` همه تأییدها خودکار «بله» می‌شوند.

## 🧭 آموزش ویزارد (ریستور و مهاجرت)

پورت پیش‌فرض: **`7000`** · ورود با توکن از URL نصب‌کننده.

### قابلیت‌ها

- ✅ ریستور بکاپ PasarGuard — حتی با تغییر نوع دیتابیس (SQLite / PostgreSQL / TimescaleDB / MySQL / MariaDB)
- ✅ رفع خودکار مشکلات نسخه TimescaleDB هنگام ریستور
- ✅ نمایش اطلاعات دیتابیس بعد از آپلود بکاپ
- ✅ گزینه غیرفعال‌سازی نودها بعد از ریستور
- ✅ مهاجرت از Marzban، 3x-ui، Hiddify و Remnawave
- ✅ دریافت استریم بکاپ از سرور مبدأ و ریستور با **تأیید دستی**
- ✅ راهنمای وضعیت پنل و دستور نصب رسمی

### مراحل ریستور / مهاجرت

۱. از پنل فعلی بکاپ بگیرید (یا از پنل بکاپ PGClockMG).  
۲. PasarGuard را با دیتابیس دلخواه روی **سرور جدید** نصب کنید.  
۳. پنل جدید را تست کنید، سپس پنل قبلی را موقتاً غیرفعال کنید.  
۴. PGClockMG را نصب کنید و URL ویزارد (با توکن) را باز کنید.  
۵. ریستور یا مهاجرت را قدم‌به‌قدم انجام دهید.

### ترتیب پیشنهادی

1. 📦 بکاپ از پنل قبلی  
2. 🛠️ نصب و تست PasarGuard روی سرور جدید  
3. ⏸️ خاموش کردن موقت پنل قبلی  
4. 🚀 اجرای ریستور/مهاجرت از ویزارد

### پشتیبانی پنل‌ها (مهاجرت)

| پنل | وضعیت |
|-----|--------|
| Marzban | کامل ✅ |
| PasarGuard | ریستور / تغییر DB (نه در مهاجرت پنل) |
| 3X-UI | کامل ✅ |
| Hiddify | ناقص (کاربران + ریدایرکت لینک) |
| Remnawave | به‌زودی |

## 💾 آموزش پنل بکاپ

پورت پیش‌فرض: **`7001`** · در اولین ورود یک **رمز قوی** می‌گذارید (حداقل ۱۲ کاراکتر، حرف بزرگ/کوچک، عدد و نماد).

### قابلیت‌ها

- 📦 **بکاپ کامل (Full bundle)** از مسیرهای رسمی PasarGuard  
  (`/opt/pasarguard` + `/var/lib/pasarguard`) — سازگار با ریستور ویزارد
- 🗄️ پشتیبانی SQLite / PostgreSQL / TimescaleDB / MySQL / MariaDB
- 📊 داشبورد سلامت سرور، دیسک بکاپ، آمار پنل و آخرین بکاپ
- ⏰ زمان‌بندی روزانه بکاپ (UTC) + نگه‌داشت آخرین N فایل
- 📱 ارسال اختیاری به **تلگرام** (یک فایل روی دیسک؛ تقسیم فقط برای آپلود بزرگ)
- 🔌 پروکسی HTTP/SOCKS برای تلگرام + تگ وضعیت **متصل / قطع**
- 🌊 **استریم** بکاپ به سرور مقصد → ویزارد مقصد تحلیل می‌کند و با تأیید دستی ریستور می‌کند
- 🔐 پنل جدا با رمز و سشن؛ پورت مستقل از ویزارد

### مراحل استفاده

۱. بعد از نصب، آدرس `http://SERVER_IP:7001/` را باز کنید.  
۲. رمز پنل بکاپ را بسازید / وارد شوید.  
۳. از داشبورد «بکاپ کامل همین حالا» بزنید یا زمان‌بندی را در تنظیمات فعال کنید.  
۴. در صورت نیاز تلگرام و پروکسی را تنظیم کنید و اتصال را تست کنید.  
۵. برای انتقال به سرور دیگر: در ویزارد مقصد «آماده دریافت استریم» را بزنید، توکن را در پنل بکاپ مبدأ بگذارید و استریم را شروع کنید — ریستور فقط بعد از تأیید دستی.

### نکات بکاپ

- فایل‌ها در `/opt/pg-migrator/backups` ذخیره می‌شوند
- تنظیمات پنل بکاپ در `/opt/pg-migrator/backup_panel/`
- رمز پنل بکاپ با توکن ویزارد فرق دارد

## ⚠️ نکات مهم

### ورود به ویزارد (توکن)

ویزارد بدون توکن باز نمی‌شود. URL چاپ‌شده توسط نصب‌کننده را باز کنید. اگر لینک را از دست دادید:

```bash
cat /opt/pg-migrator/.access_token
```

توکن با دسترسی `0600` ساخته می‌شود — در چت یا اسکرین‌شات عمومی نگذارید.

### بعد از مهاجرت 3x-ui / Hiddify لینک‌های قدیمی کار نمی‌کنند؟

`pg-redirect` باید روی پورت پنل قبلی بالا بیاید. اگر پنل قبلی هنوز روشن باشد پورت را نگه می‌دارد. اسکریپت → گزینه `3` (Redirect server) → `2` (Force restart).

## 🛠️ دستورات کاربردی

```bash
# ویزارد
systemctl status pg-migrator
systemctl restart pg-migrator
journalctl -u pg-migrator -f

# پنل بکاپ
systemctl status pg-backup
systemctl restart pg-backup
journalctl -u pg-backup -f
# یا لاگ فایل:
tail -f /opt/pg-migrator/logs/backup-service.log

# به‌روزرسانی هر دو
sudo bash -c "$(curl -fsSL 'https://raw.githubusercontent.com/Mrclocks/PGClockMG/main/install.sh?v='$(date +%s))"

# توقف
systemctl stop pg-migrator pg-backup
systemctl disable pg-migrator pg-backup
```

نقطهٔ ریستور قبل از `v4.0.0`: تگ Git `restore-point-pre-v4.0.0`
